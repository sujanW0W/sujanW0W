I'm a software engineer who builds AI systems at the intersection of software engineering and LLM research. I spent 1.5 years building full-stack and AI-powered applications in industry, interned at **NCSA (UIUC)** through the **NSF ACCESS** program building an LLM-powered auditing tool, and my research on LLM evaluation and machine unlearning, **ShadowBench**, was accepted at **NeurIPS 2026** (Evaluations & Datasets Track).
 
These days I focus on **LLM applications**, **agentic systems**, and **LLM evaluation**. I've worked with tools and frameworks such as:
 
- 🤖 LLMs & Agents: LangGraph, LangChain, Model Context Protocol (MCP), RAG, Prompt Engineering, Hugging Face Transformers
- 📏 Evaluation & Serving: LLM-as-a-judge, Benchmark Design, vLLM, Weights & Biases
- 🧠 Machine Learning: PyTorch, Fine-tuning, Distributed Training (HPC), Scikit-learn, NumPy, pandas, Matplotlib
- ⚙️ Backend: FastAPI, Django, Node.js, Express.js, REST APIs, Celery, RabbitMQ, Redis
- 🌐 Frontend: React, Next.js, TypeScript, Tailwind CSS, Astro
- 🗄️ Data & Tools: PostgreSQL, MongoDB, Vector Databases, Docker, Git, GitHub Actions, AWS, Linux


## 📌 Featured Work
 
- 📄 **[ShadowBench](https://github.com/sujanW0W/ShadowBench)**: exposing lexical anchoring and the "illusion of forgetting" in LLMs (NeurIPS 2026, [paper](https://arxiv.org/abs/2611.15925), [project page](https://sujanw0w.github.io/ShadowBench/))
- 🩺 **[Medical Chatbot](https://github.com/sujanW0W/Medical-Chatbot)**: multi-agent RAG with LangGraph, an async FastAPI backend, and an LLM evaluation harness
- 🛰️ **[CiDeR GenAI Tool](https://github.com/access-ci-org/step-2026-cider-genai-tool)**: LLM auditor keeping national cyberinfrastructure records in sync (NSF ACCESS / NCSA)
## 🎯 Current Focus
 
- Building reliable, production-ready LLM applications and agentic workflows
- Researching LLM evaluation and AI safety
- 🔍 Open to full-time **AI Engineer / Software Engineer** roles starting summer 2027
